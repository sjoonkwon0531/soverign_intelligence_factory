# 국가 소버린 AI 추진체계 시뮬레이터

대한상공회의소 「국가 소버린 AI 추진체계 구축 방안」 보고서(책임연구 권석준, 2026)의 계량 모형을 누구나 실행하고, 새 자료로 다시 계산하고, 대안을 평가할 수 있도록 만든 Streamlit 앱입니다.

## 이 도구로 답할 수 있는 질문

- 새 모델이 나와 격차가 바뀌면 권고안의 성공 확률과 재무 부담은 어떻게 달라지는가
- 같은 예산을 부처별로 나눌 때와 한 주체로 모을 때 무엇이 얼마나 다른가
- 민간 대기업과 프런티어 랩이 대규모 AI 데이터센터를 짓는다면 국가 SPC는 여전히 필요한가, 필요하다면 어떤 규모와 형태인가
- 소버린 AI의 편익은 어디에서 나오는가: AI 효과의 크기가 아니라 국내 귀속, 수입 대체, 차단 위험
- 예비타당성조사 틀(사회적 할인율 4.5%)로 보면 대안별 편익비용비는 얼마인가
- 어떤 불확실성이 결론을 뒤집는가, 그 신호를 언제 관측해 멈출 것인가

## 내 컴퓨터에서 실행

Python 3.10 이상이 필요합니다.

```bash
pip install -r requirements.txt
streamlit run streamlit_app.py
```

브라우저에서 `http://localhost:8501` 이 열립니다.

## GitHub에 올리기

1. GitHub에서 새 저장소를 만듭니다(예: `kcci-sovereign-ai-sim`). 내부 검토 단계라면 Private을 권합니다.
2. 이 폴더에서 다음을 실행합니다.

```bash
git init
git add .
git commit -m "소버린 AI 추진체계 시뮬레이터 초판"
git branch -M main
git remote add origin https://github.com/<계정>/kcci-sovereign-ai-sim.git
git push -u origin main
```

GitHub 웹에서 폴더를 끌어다 놓아 올려도 됩니다(Add file, Upload files).

## Streamlit Community Cloud에 배포

1. https://share.streamlit.io 에 GitHub 계정으로 로그인합니다.
2. Create app, Deploy a public app from GitHub(또는 비공개 저장소)를 고릅니다.
3. 저장소, 브랜치 `main`, Main file path `streamlit_app.py` 를 지정하고 Deploy를 누릅니다. 첫 배포는 패키지 설치로 몇 분 걸립니다.
4. 비공개로 쓰려면 비공개 저장소에서 배포하거나 앱 설정의 Sharing에서 Only specific people can view this app을 고른 뒤, 상의 담당자 이메일을 초대합니다. Community Cloud는 비공개 앱을 한 번에 하나만 허용하고, 초대받은 사람도 다른 사람을 초대할 수 있으므로 내부 자료가 들어가면 사내 서버 배포를 검토하십시오.
5. 코드를 GitHub에 다시 올리면 앱이 자동으로 갱신됩니다.

## 자료 갱신

- 데이터 관리 화면에서 Epoch AI의 역량지수(ECI), Notable AI Models 파일, AA 점수 대응표, 한국 모델 점수를 올리거나 링크를 붙입니다. CSV, XLSX, ZIP, JSON을 자동으로 판별합니다.
- 격차 진단 화면이 새 자료로 프런티어 속도, 연산 효과, 한국 출발점, 오픈웨이트 간격을 다시 추정하고 시뮬레이션 모수를 제안합니다. 적용을 누르면 이후 모든 화면이 새 모수로 계산됩니다.
- 기준본을 바꾸려면 `data/baseline/` 의 파일을 교체하고 저장소에 올립니다.

## 재현

기본 모수(본보고서 r1, 2026. 9. 30.)와 시드 20260930, 3,000회에서 본보고서 수치가 그대로 나옵니다.

```bash
pip install pytest
pytest tests/
```

`tests/test_reproduce.py` 는 시나리오(권고안 도메인 게이트 0.306, 누적 재무 갭 3.27조원, 프런티어 격차 0.99년), 비용편익(순편익 −0.21조원, 양일 확률 0.42), 격차 진단(프런티어 연 15.76점, 연산 10배당 3.09점), 부가가치(5.74, 10.48조원), 공공수요 적산 합계를 확인합니다. `tests/test_smoke.py` 와 `tests/test_actions.py` 는 모든 화면과 주요 버튼이 오류 없이 동작하는지 확인합니다.

## 해석 원칙

- 모든 확률과 금액은 명시된 가정에 따른 조건부 추정치입니다. 인용할 때는 시나리오 간 순위와 감도를 중심으로 하고, 기준일·모수·반복 횟수를 함께 적어 주십시오.
- 거시 효과의 절대 수준은 한국은행(2025) 추정 범위에 의존하므로 시나리오 간 차이로만 해석합니다.
- 미시(비용편익)와 거시 편익, 국내 귀속 부가가치와 산업연관 파급효과는 서로 더하지 않습니다.
- 2025 명목 GDP 기본값(2,600조원), 공공자금 한계비용, AHP 가중치는 잠정 또는 사용자 입력값입니다.

## 자료 출처와 이용 조건

- Epoch AI 자료(Epoch Capabilities Index, Notable AI Models, AI Chip Owners, GPU Clusters, AI Data Centers Hub, ML Hardware)는 CC BY 4.0으로 제공되며, 이 앱과 재배포본에 출처(Epoch AI)를 표시해야 합니다.
- Artificial Analysis 점수는 본보고서의 환산에 쓴 대응표만 포함했습니다. 공개 배포 전에 Artificial Analysis의 이용 조건을 확인하십시오.
- 한국은행 산업연관표, 과학기술정보통신부 예산안, 공공부문 SW·ICT 수요예보는 공공 자료입니다.
